# 臺中市社宅生活學校集點系統

本專案為「臺中市住宅發展工程處」與「好伴社計」合作開發之社會住宅住戶完課集點與身分驗證系統。

## 🛠️ 技術架構
- **後端平台**：Google Apps Script (GAS)
- **資料庫**：Google Sheets (試算表整合)
- **前端介面**：HTML5, CSS3 Grid 佈局 (同步台中好宅活動地圖亮黃色調 UI), JavaScript (V8)
- **視覺資產**：採用內嵌式 Base64 Image 編碼，確保專案無外部破圖風險

## 📋 功能模組
1. **住戶身分驗證**：初次登入自動比對社宅住戶名冊。
2. **驗證進度查詢**：即時追蹤人工審核狀態。
3. **完課累積點數**：住戶上課簽到後自主登錄。
4. **點數查詢及兌換**：整合持有總點數、本次消費與剩餘點數之動態計算。
5. **相關連結指南**：時髦方格（1大2小）直覺引導至活動地圖與官方 LINE。
